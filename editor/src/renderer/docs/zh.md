#! 入门

# 皮肤是什么、放在哪 {#what}

ForgeSkin 分两部分：

- **ForgeSkin 插件**装在 r2modman 的游戏配置档里，在游戏中给你的枪、近战武器、工具和物品换上皮肤，也能把你的人物换成导入的人形模型。
- **这个编辑器**用来做枪皮和人物皮肤、预览、一键装进游戏，以及打包分享。左栏上方的 **武器皮肤** 和 **人物模型** 切换做哪一种。

![本教程做出来的示例皮肤：OMNECO LRG 上的「余烬线」](shot:example-final)

## 需要准备什么

- 装好 GTFO。编辑器会自己找游戏；找不到时，3D 视图里会让你选游戏文件夹（里面有 `GTFO.exe`）。
- 一个装了 **BepInExPack_GTFO** 的 r2modman 配置档。ForgeSkin 插件和它依赖的 ForgeCore，会在你第一次点作品卡上的 **应用** 时由编辑器装好，不用自己下载。

## 先知道这几点

- 队友**装了同一个皮肤包**才能在你的枪和炮台上看到你的皮肤、玩家颜色和调整（发布成 Thunderstore 模组方便他们装）。没装或装的是别的版本，他们看到的是枪的原样。
- 做好的皮肤打包成 `.forgeskin` 皮肤包，编辑器把它装进配置档的 `BepInEx/ForgeSkin/skins` 文件夹。
- 游戏里点**大厅里的「皮肤」按钮**，给每件装备选皮肤、改皮肤的可调颜色、调代码特效。关卡里打不开。

## 从哪开始

1. 先看一遍[编辑器一览](#editor)。
2. 做枪皮：跟着[完整示例](#example)一步步做出一款科幻步枪皮肤。
3. 做人物：先看[人物模型一览](#character)，再跟着[导入一个 VRM 人物](#char-example)走一遍。
4. 需要时再查其他页：贴图、涂装、颜色、动态效果、挂件这些枪皮的细节在后面几组里。左上角的搜索框也能搜到页面里的文字。

# 编辑器一览 {#editor}

![选中一个部件时的编辑器。编号对应下面的列表。](shot:editor-map)

1. **左侧面板。** 当前装备的 **部件与挂件** 列表：每个部件下面列着它的涂装层、动态图层、代码特效和挂件。勾选框决定部件装不装，眼睛隐藏这一行（游戏里也隐藏），行上的 **+** 给这个部件加任何东西。左边缘的 **作品** 切到作品列表。
2. **装备名。** 点它（或按 <kbd>Ctrl</kbd>+<kbd>P</kbd>）换一把武器、工具或物品。
3. **事件按钮。** 击杀、命中、开火、装备等按钮，按游戏的规则播放皮肤的特效、动态图层和音效。
4. **右侧面板。** 选中对象的设置。什么都没选时显示皮肤的 **概览**。
5. **右边缘的标签。** 右侧面板的分类。部件有 **贴图**、**涂装**、**动态**、**挂件**、**位置**、**音效**；挂件有 **位置**、**外观**、**屏幕**（只有弹药屏）、**特效**、**音效**。标签上的小数字是里面有几项。
6. **发布。** 体检、导出皮肤包或 Thunderstore 模组、导出模型和 UV 模板、直接写游戏文件。
7. **应用。** 在作品卡上：打包皮肤、装进左栏顶部 **应用到：** 选的档案，并让游戏里的这件装备穿上它。

这里说的是顶栏左边选 **武器** 时的样子；选 **人物模型** 时见[人物模型一览](#character)。

## 操作视图

- 在 3D 视图里拖动转枪，滚轮缩放，右键拖动平移。
- 在 3D 视图里点一下选中部件或挂件，细的套环和挂饰链子点在旁边几个像素内也算。鼠标停在左侧列表的一行上，3D 里对应的东西会亮起来；停在 3D 里的东西上，列表里那一行也会亮。
- <kbd>F</kbd> 或 **对准选中** 把镜头对准选中的东西。
- 小键盘 <kbd>1</kbd> 前、<kbd>3</kbd> 右、<kbd>7</kbd> 顶，加 <kbd>Ctrl</kbd> 看反面；<kbd>5</kbd> 切换透视和正交；<kbd>0</kbd> 对准选中。右上角的方块点一下也一样。
- <kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤销，<kbd>Ctrl</kbd>+<kbd>Y</kbd> 重做。每次改动是一步撤销。
- 带箭头的小节标题可以折叠，下次打开还是折着的。

> [!TIP]
> 鼠标停在标题或设置旁的小 **i** 上，会显示一句说明。

# 选装备、建皮肤 {#start}

## 选一件装备

1. 点 3D 视图左上角的装备名，或按 <kbd>Ctrl</kbd>+<kbd>P</kbd>。
2. 在顶部搜索，或用槽位标签（主武器、特殊武器、近战、工具等）筛选。
3. 点一张卡片。3D 视图载入这件装备；第一次打开要几秒钟。

![装备列表](shot:gallery)

## 一件装备的皮肤

每件装备可以有好几款皮肤。点左边缘的 **作品** 看作品卡，同一件装备的排在一组。

![作品列表](shot:skins-panel)

- 点卡片切换到那件作品。
- **＋ 新建** 选一件装备就建一件新作品；旁边的箭头里有 **复制当前这个**、**打开工程或旧版预设…**（<kbd>Ctrl</kbd>+<kbd>O</kbd>）、**导入 Skins 皮肤组…**。
- 卡片的 **⋯** 菜单：**装进档案**、**复制**、**改名**、**导出皮肤包…**、**版本快照**、**保存为文件…**、**清空当前改动**、**删除作品**。双击名字也能改名。
- 卡片上写着它在当前档案里的状态（只在编辑器、在档案里、正在用），见[装进游戏](#save)。

## 导入 Skins 皮肤组

**导入 Skins 皮肤组…** 要你选皮肤组文件夹里的 `manifest.skingroup.json`。皮肤组里写到的每把武器各得到一个皮肤；适用于几把武器的材质设置会放进每一个，贴图宏（如 `@NORMAL`、`@CHECKER(...)`）会变成小图片。没写武器编号的皮肤组在 Skins 里不会套到任何武器上，所以编辑器会问你放到哪把武器（也可以取消）。导入后会打开一份清单，列出没带过来或被改动的内容，点开能看到每一项。

#! 做一把枪皮

# 完整示例：一把科幻步枪 {#example}

这一页从头到尾做一款枪皮：给 **OMNECO LRG**（HEL 步枪）做一款干净的科幻皮肤 **余烬线**（Ember Line）：白灰色枪身，黑色弹匣和瞄具，发光的橙色面板缝，一条警示条，一串编号，一块弹药屏，瞄具前的全息刻度准星环，再挂一个小全息挂饰，最后装进游戏、导出给别人。每一步用的功能在后面的页里都有细说，点链接看细节。

![做好的余烬线](shot:example-final)

## 1. 打开步枪，新建皮肤

1. 确认顶栏左边选的是 **武器**。
2. 按 <kbd>Ctrl</kbd>+<kbd>P</kbd>，输入 `LRG`，点 **OMNECO LRG**。
3. 左边缘 **皮肤** → **新皮肤** → **新建空白皮肤**。双击名字改成 **余烬线**。

## 2. 底漆和漆面

配色：白灰 `#949699`、灰 `#5C6166`、黑 `#0D0E0F`、橙 `#FF6B14`。

1. 选中 **前部**，打开[涂装](editor:livery)，点 **底漆**。颜色 `#949699`，**不透明度** 0.85，让游戏贴图的细节透出来。**漆面** 选 **烤漆钢**。
2. **机匣** 照做一遍。（或选中这层底漆，用 **应用到其他部件**。）
3. **枪托**：底漆 `#5C6166`，不透明度 0.92，漆面 **缎面**。
4. **弹匣** 和 **瞄具**：底漆 `#0D0E0F`，不透明度 0.92；弹匣漆面 **橡胶**，瞄具 **缎面**。

> [!TIP]
> 现在就把这四个颜色存成调色板：**概览** → **调色板**，输入 `余烬`，点保存。再点一下它，所有取色器下面都会列出这四个颜色。

![第 2 步之后](shot:example-base)

## 3. 发光面板线

1. 选中 **前部**，**涂装** → **面板线**，选 **装甲分格** 预设。
2. 在 3D 视图里点前部长而平的侧面，拖动到格子落在散热孔之间。
3. **位置** 里大小设成约 220 × 50 毫米，打开 **左右对称**。
4. **面板线** 里：**线宽** 0.6 毫米，**切角** 3 毫米，**格间距** 2 毫米，**数量** 4。
5. **外观** 里：颜色 `#FF6B14`，打开 **发光**。

![左：之前。右：打开发光的面板线。](shot:panel-lines-before-after)

## 4. 警示条、编号和枪托渐变

1. 在 **前部** 上再加一层 **面板线**，选 **黄黑警示** 预设，颜色橙色，关掉发光。放在枪口附近，70 × 12 毫米，打开 **左右对称**。
2. 在 **机匣** 上加 **文字**：`EMBER-07`，字体 Orbitron，**字高** 8 毫米，**字距** 0.12，颜色接近黑色。放在扳机上方的侧面，打开 **左右对称**。
3. 在 **枪托** 上加 **渐变**。颜色：15 % 处灰色，85 % 处黑色。**方向**：**沿枪身**。不透明度 0.9。

![第 4 步之后](shot:example-lines)

## 5. 弹药屏

1. 选中 **机匣**，**挂件** → **添加挂件** → **弹药屏**。
2. 把它移到机匣左侧、导轨下方，转成朝外（按 <kbd>R</kbd>，或在 **位置** 里把 **旋转 °** 设成 0, 90, 0）。
3. **屏幕**：**显示** 弹匣内子弹，**位数** 2，尺寸 40 × 18 毫米。
4. **外观** → **颜色**：文字橙色，底板黑色 90 %，边框橙色，**边框样式** **四角折角**。**低弹药变色** 保持打开。
5. 点几下视图下面的 **模拟开火**，看它往下数。

## 6. 全息刻度准星环

1. 选中 **瞄具**，**挂件** → **添加挂件** → **形状** → **刻度准星环**。它已经是橙色的（皮肤里第一个有颜色的涂装层）。
2. 把它移到瞄具镜片的正前方。
3. **外观**：**半径** 16 毫米，**刻度数** 36。
4. **全息**：**闪烁** 0.15，**亮度** 0.9，打开 **双色渐变**，上方颜色用暖白，**扫描线** 0.5，**轮廓光** 0.6。

![刻度准星环：只有闪烁（左）和加上渐变、扫描线、轮廓光（右）](shot:hologram-before-after)

> [!NOTE]
> 扫描线和轮廓光占皮肤 8 个代码特效名额中的两个。这款皮肤没有别的代码特效，名额够用。

## 7. 一个小全息挂饰

1. 选中 **前部**，**添加挂件** → **挂饰** → **蜂巢护盾**。它挂在前部下面。
2. 在 **位置** 里设绳子：**链**，**长度** 3.5 厘米，深灰色。点 **跑动** 和 **转身** 看它甩起来。
3. 打开 **外观**，打开 **全息**（闪烁 0.3），让它和准星环一样发光。

![瞄具特写：刻度准星环和弹药屏](shot:example-sight)

## 8. 检查并装进游戏

1. **发布** → **检查**：应该显示没问题。
2. 点余烬线卡片上的 **应用**。启动游戏，步枪已经穿上余烬线；游戏开着的话几秒内就换上。详见[保存、快照和装进游戏](#save)。
3. 想试别的点子（比如一套夜间配色变体）之前，先存一个 **版本快照**（卡片 **更多** → **版本快照**）。

## 9. 导出给别人

1. **发布** → **导出为 Thunderstore 皮肤模组…**，勾上余烬线，填模组名、版本、简介，选 **ForgeSkin** 格式。
2. 导出的 zip 自己上传到 Thunderstore。队友装了这个模组，才能在你的枪上看到余烬线。详见[发布和分享](#publish)。

#! 做一个人物

# 人物模型一览 {#character}

除了枪，你还可以把自己在游戏里的人物整个换成一个导入的人形模型。游戏里它照原版的动作走、跑、蹲、跳、持枪、倒地，原版人物藏起来；中弹的范围还是原版的，模型只管好看。人物皮肤和枪皮一样，一个皮肤打成一个包，可以装进游戏试穿，也可以导出成 Thunderstore 模组。

![人物模型这一边：1 左边的六步，2 动作栏，3 当前这一步的设置](shot:character-map)

## 换到人物这一边

点左栏上方的 **人物模型**（旁边是 **武器皮肤**）。窗口换成人物的样子，再点 **武器皮肤** 回到枪皮，两边的东西互不影响。

## 窗口里有什么

- **左边**：六步，从上往下做：**导入模型**、**骨骼匹配**、**第一人称手臂**、**头发与裙摆**、**材质**、**检查**。每一步旁边的标记：勾表示这一步好了，红色数字是还有几处要处理，**头发与裙摆** 旁的数字是有几组会摆动的骨头，标着 **之后** 的一步这一版还不能用。
- **中间**：3D 视图。拖动转模型，滚轮缩放，右键拖动平移。下面是[动作栏](#char-motion)，左下角的 **显示骨骼** 在模型上画出骨架。
- **右边**：左边选中那一步的设置。
- **左栏的作品卡**：人物卡上的 **应用** 装的是人物皮肤，不是枪皮。

改动会自动保存。下次切到 **人物模型**，上次做的人物会自己打开。

## 按什么顺序做

1. [导入模型](#char-import)
2. [骨骼匹配](#char-bones)：全部变绿才能往下。
3. [动作预览](#char-motion)：放几段动作看模型动起来对不对。
4. [头发、裙摆和身体挡板](#char-springs)
5. [材质和第一人称手臂](#char-materials)
6. [装进游戏和导出](#char-export)

第一次做，跟着[完整示例](#char-example)走一遍最快。

# 导入模型 {#char-import}

## 准备什么样的模型

- 带人形骨架、做了蒙皮的 `.glb` 或 `.vrm`。Mixamo、VRoid、Blender 导出的都可以。
- 骨头最多 256 根，顶点最多 100 万个。
- 贴图是 PNG 或 JPEG，每个顶点最多受 4 根骨头影响，导出成单个文件、不压缩。
- `.vrm` 最省事：文件里写好的骨骼、会摆动的头发裙摆、碰撞体和作者要求的署名，导入时都会直接填好。

## 导入

1. 切到 **人物模型**。
2. 点 3D 视图中间的 **选择模型文件**，选你的模型；或者直接把 `.glb`、`.vrm` 文件拖进窗口。
3. 等几秒。成功时右下角会提示导入了多少根骨头；`.vrm` 还会说按文件填好了几组摆动骨和几个碰撞体。
4. 编辑器自动跳到 **骨骼匹配**。

![导入后的「导入模型」这一步](shot:character-import)

做对了：3D 视图里站着你的模型，左边 **导入模型** 旁打了勾。

## 「导入模型」这一步里有什么

| 设置 | 作用 |
| --- | --- |
| 皮肤名 | 这个人物皮肤的名字，导出模组时的模组名默认按它取。 |
| 署名 | 只有模型的许可证要求署名时才出现。导出时会写进包里的 CREDITS.txt 和模组说明。 |
| 骨头、顶点、材质 | 这个模型有多少，导出前会和上限比对。 |
| 换一个模型 | 换成另一个文件。 |

## 导入不进来

失败时右下角会说原因，常见的几种：

| 提示 | 怎么办 |
| --- | --- |
| 这个模型没有蒙皮 | 在 Blender 里绑好骨骼再导出 `.glb`。 |
| 模型里有同名的骨头 | 给每根骨头起不同的名字再导出。 |
| 顶点、面数或材质太多 | 减面、合并材质后再导出。 |
| 模型是压缩过的 | 导出时关掉压缩。 |
| 有顶点受超过 4 根骨头影响 | 导出时限制成每个顶点 4 根。 |
| 贴图不是 PNG 或 JPEG | 换成 PNG 或 JPEG 再导出。 |

# 骨骼匹配 {#char-bones}

人物在游戏里跟着原版身体动，编辑器得先知道你模型里哪根骨头是髋、哪根是手。导入时已经按骨头的名字自动认了一遍，这一步只处理没认出来或认错的。打开[骨骼匹配](editor:character-bones)。

![骨骼匹配：人形、手指格子和关节对应的骨头](shot:character-bones)

## 看人形

- 右边的小人上每个圆点是一个关节：**绿色** 对上了，**红色** 要处理，**灰色** 没指定（不是必需的关节可以空着）。
- 下面两块格子是左右手各 15 节手指。一只手的手指全对上了，旁边写 **会动**；没全对上写 **不动**，游戏里这只手的手指保持模型原来的样子。
- 3D 视图里，对上的关节也是绿点，点一个就选中它。

## 处理问题

问题列在小人上方，点一条就选中那个关节：

| 提示 | 意思 |
| --- | --- |
| 缺「左手」，点这里指定 | 必需的关节没找到骨头。 |
| 「A」和「B」在同一个点上 | 两个关节指到了同一处，多半指错了骨头。 |
| 「X」偏了 N° | 骨头指错了，或者模型不是站直的。 |
| 「X」在身体右边：左右指反了 | 左右两边对调了。 |

必需的关节：髋、腰、脊、颈、头、左右肩、左右上臂、左右前臂、左右手、左右大腿、左右小腿、左右脚。

## 手动指定一个关节

1. 在小人或手指格子上点那个关节。
2. 在下面 **点一个关节** 那块的下拉里选模型里对应的骨头，可以输入名字搜索。
3. 想撤回这一个，点 **用自动匹配的**；想全部重来，点上方的 **重新自动匹配**。

做对了：上方写着 **骨骼都对上了，姿势核对通过。**，左边 **骨骼匹配** 旁打了勾。没到这一步之前，动作栏是灰的，也不能装进游戏或导出。

> [!NOTE]
> 模型整体朝后时，这里会写一句「模型整体朝后，游戏里会转过来用」，不用你处理。

# 动作预览 {#char-motion}

3D 视图下面的动作栏让模型动起来，看绑得对不对。

![动作栏：上面一行是游戏里的动作，下面一行是试动作](shot:character-motion)

## 两组动作

| 组 | 有哪些 | 用来干什么 |
| --- | --- | --- |
| 游戏里的动作 | 站立、走、跑、蹲、蹲走、跳、持枪、开火、换弹、近战、倒地、被救起 | 原版玩家的动作。进游戏后你的人物就是这样动的，这一组看到的就是真实效果。 |
| 试动作 | 街舞、扭臀舞、僵尸走、后空翻、祈祷、握手、躺着耸肩、躺地抽搐 | 幅度很大的动作，只用来看模型绑得好不好（手臂扭不扭、衣服会不会撕开），游戏里不会出现。 |

## 播放

1. 点一个动作，它马上开始播。
2. **播放** / **暂停** 停在当前这一帧，方便细看。
3. **循环** 打开时一直重复播；关掉只播一遍。
4. **速度** 选 0.25×、0.5× 或 1×，慢放看手和脚。
5. **回到静止** 停下动作，模型回到导入时的姿势。

骨骼还没对上时整栏是灰的，鼠标停上去会提示先把骨骼配好。

## 看什么

- 走、跑时脚落在地上，膝盖朝前弯。
- 持枪、换弹时手臂不扭成麻花，手指能握起来。
- 头发和裙摆随动作摆起来，不穿进身体。
- 不放动作时头发裙摆应当是静止的；一直在晃就是有问题。

## 晃一下、跑动、转身

3D 视图下方和 **头发与裙摆** 这一步的标题旁都有 **晃一下**、**跑动**、**转身** 三个按钮：手动给模型来一下，专门看头发裙摆怎么甩。至少有一组会摆动的骨头时才能点。

# 头发、裙摆和身体挡板 {#char-springs}

把头发、马尾、裙摆、飘带的骨头设成会摆动，游戏里它们跟着人物甩。打开[头发与裙摆](editor:character-springs)。`.vrm` 导入时已经按文件填好了。

![头发与裙摆：摆动骨卡片和身体挡板](shot:character-springs)

## 加一组摆动骨

1. 点 **选一根骨头，加摆动**，选这串骨头最上面那根（比如马尾的根），可以输入名字搜索。
2. 它下面有几串骨头就算几串，一起摆（裙摆一圈就是好几串）。下面没有骨头的会提示「摆不起来」，换更上面的一根。
3. 新卡片按骨头名字猜好 **类型**，不对就改。
4. 点 **晃一下**、**跑动** 或 **转身** 看效果，再调滑块。

## 每组的设置

卡片标题是这串骨头最上面那根的名字，几串就写 ×几。

| 设置 | 范围 | 作用 |
| --- | --- | --- |
| 类型 | 长发、马尾 / 短发 / 裙摆 / 尾巴、飘带 | 一组起步的数值。换类型会把硬度、停得快和粗细换成这一类的。 |
| 硬度 | 0 到 1 | 多大程度保持原来的形状。 |
| 停得快 | 0 到 1 | 甩完多快停下。 |
| 重量 | 0.1 到 3 | 越重甩得越慢越远。 |
| 重力 | 0 到 3 | 往下坠的力气。 |
| 粗细 | 0 到 10 厘米 | 碰撞时这串骨头算多粗。 |

垃圾桶（**不再摆动**）删掉这一组。

## 身体挡板

在这一步，3D 视图里会出现蓝色的胶囊。头发和裙摆碰到它们会被推开，不穿进身体。

- 没有文件自带的碰撞体时，用自动的七个：头、胸、髋、左右大腿、左右小腿。每个能单独开关，滑条调粗细（原来的 0.5 到 2 倍）。
- `.vrm` 自带碰撞体时，列出每一个和它的粗细，垃圾桶去掉一个；**改用自动碰撞体** 换成上面那七个。

做对了：点 **跑动**、**转身** 时，头发和裙摆甩起来、贴着身体滑过去而不是穿进去。

> [!NOTE]
> 游戏里你自己和队友的人物都会摆，各自算各自的，所以每个人看到的摆法不完全一样。

# 材质和第一人称手臂 {#char-materials}

## 材质

打开[材质](editor:character-materials)，模型的每个材质一行，**着色器** 决定它怎么受光。现在只有 **游戏受光** 一种，和游戏里的装备一样受光。

<!-- 待补：卡通着色器进编辑器后，这里加「着色器」下拉里的卡通一项和它的参数。 -->

## 第一人称手臂

第一人称里看到的手臂由游戏从你的模型里自己取：留下蒙皮在上臂及以下的部分（前臂、手、手指、袖子），每个关节放到游戏自己的手臂上，所以拿任何武器手都握在原版的位置。不用另做一个模型。打开 **第一人称手臂** 这一步（骨骼对上以后才能用）：

1. 点 **看第一人称手臂**，或者在 3D 视图上方把 **整个模型** 切到 **第一人称手臂**。视图里只剩游戏会留下的那部分，切法和游戏里是同一份代码。
2. 会挡住瞄具的材质（比如宽大的袖口），在下面它的那一行打开 **第一人称里不画**，手臂视图里它马上消失，游戏里也一样不画。
3. 下面的动作在手臂视图里同样能播，看握枪、换弹时手指和袖子的样子。

模型没有蒙皮在手臂上的部分时会提示，第一人称仍是原版手臂。卡通材质在第一人称手臂上按受光画。

# 装进游戏和导出 {#char-export}

## 装进游戏试穿

1. 骨骼对上以后，点左栏人物卡上的 **应用**。
2. 编辑器打包人物、装进左栏顶部 **应用到：** 选的档案，并让你在游戏里穿上它，卡片变成 **正在用**。
3. 游戏开着时，下次进关卡生效。
4. 想换回原版人物，在游戏大厅点 **皮肤**，在左边最上面的 **人物** 一格里换，包留在档案里。

骨骼没对上时点 **应用** 会提示先把骨骼对上。

## 卡通渲染设置

人物包里标成卡通（`toon`）的材质，每个玩家可以自己选怎么画。在大厅点 **皮肤**，再点挑选器标题栏的齿轮；**皮肤设置 · 所有装备** 里的 **卡通渲染** 有三个选项：

| 选项 | 画法 | 热成像镜 |
| --- | --- | --- |
| **延迟**（默认） | 用游戏自己的灯光、阴影和雾照亮，明暗分阶是近似的。 | 看得到。 |
| **前向** | 按游戏的灯光自己算分阶明暗，卡通感更干净。 | 看不到这些卡通部分。 |
| **关闭** | 和其他表面一样按受光画。 | 看得到。 |

改了马上作用于所有已经穿上的人物（包括大厅里的人物），写进 `ForgeSkin.cfg`，下次进游戏还在。这只是你自己屏幕上的显示，不发给队友，队友各自选。默认是延迟，因为用前向时热成像镜里看不到队友身上的卡通部分。

> [!WARNING]
> 应用会往那个配置档里写真实的文件。请用专门测试的配置档。

## 导出

在人物这一边点顶栏的 **导出** → **导出为 Thunderstore 皮肤模组…**。左边最后一步 [检查](editor:character-check) 列着同样的检查项。

![导出：检查项和模组信息](shot:character-export)

1. 上面四项检查都要打勾：**必需的关节都有骨头**、**静止姿势核对**、**骨头**（最多 256）、**顶点**（最多 100 万）。
2. 有署名的模型会写一行「包里会带上署名：……」。
3. 填 **模组名**（只能用英文字母、数字和下划线，默认按皮肤名取）、**版本**（形如 1.0.0）、**简介**（最多 250 字），**图标** 默认是 3D 视图的画面，**换一张图片…** 换成你自己的。
4. 点 **导出 Thunderstore 模组…**，选保存位置，得到一个可以上传 Thunderstore 的 zip。只想要皮肤包本身，点 **只导出皮肤包…**，得到一个 `.forgeskin`。
5. 上传由你自己在 Thunderstore 网站上做。队友装了这个模组，才能看到你的人物；没装的人看到的是原版人物。

# 完整示例：导入一个 VRM 人物 {#char-example}

这一页从头到尾把一个 VRoid 做的 `.vrm` 人物装进游戏。

1. **切过去。** 点左栏上方的 **人物模型**。
2. **导入。** 把 `.vrm` 拖进窗口。右下角提示导入了多少根骨头、填好了几组摆动骨和碰撞体，编辑器跳到 **骨骼匹配**。
3. **核对骨骼。** VRM 的骨骼一般直接全绿，上方写着 **骨骼都对上了，姿势核对通过。** 有红点就按[骨骼匹配](#char-bones)处理。
4. **放动作。** 在动作栏点 **走**、**跑**、**持枪**、**换弹**，看脚和手对不对；再点几个 **试动作** 看大动作时有没有撕裂。点 **回到静止**。
5. **调头发裙摆。** 左边点 **头发与裙摆**，点 **跑动** 和 **转身**。头发甩得太软就把 **硬度** 调高一点，裙摆穿进腿里就把身体挡板的大腿、小腿调粗一点。
6. **起名。** 左边点 **导入模型**，在 **皮肤名** 里改个名字。
7. **试穿。** 点人物卡上的 **应用**，进游戏就穿上了。
8. **导出。** 顶栏 **导出** → **导出为 Thunderstore 皮肤模组…**，填模组名和版本，点 **导出 Thunderstore 模组…**。

# 贴图 {#textures}

选中一个部件（在 **部件与挂件** 列表里，或在 3D 视图里点它），再点右边缘的[贴图](editor:texture)。

![机匣的贴图页：四个槽、发光和材质参数](shot:textures-tab)

| 槽 | 放什么 |
| --- | --- |
| 基础色 | 表面的颜色和图案，最常改的就是它。 |
| 法线 | 凹凸和细节。按常见的切线空间法线图做；打包时会转成游戏要的格式。 |
| 金属/光滑 | 金属感和光泽：红色通道是金属度，绿色通道是光滑度（游戏装备着色器的排法）。 |
| 自发光 | 哪里会亮。换上以后设发光的 **颜色** 和 **强度**；**应用到全部部件** 一次设好整把枪。 |

一个部件有多个材质时，这一页顶部会有 **材质** 列表，先选你要改的那个。

## 换一张贴图

1. 点一个槽选图片，或从资源管理器把一张图拖到槽上。拖到上面时槽会亮起并标出通道名。
2. 角标从 **原版** 变成 **已替换**。**×** 换回原版。

一次拖多个文件，或拖了不是图片的文件，槽会变红并说明原因。

## 一次换整把枪

把一个贴图文件夹（比如 Substance Painter 导出的）拖到窗口任意位置，或点 **整枪文件夹**。文件名里带部件和通道的（如 `Receiver_BaseColor.png`）会自动对上。编辑器拿不准的会标黄，逐个点 **没错**，或在 **概览** 里点 **全部没错**。对不上的文件列在 **概览** 里。

在 Photoshop 或 Substance Painter 里重新保存一次图片，编辑器会自动重新读取。

## 材质参数

**材质参数** 下有 **金属度**、**光滑度** 和 **颜色叠加**，前提是游戏的这个材质有这些项。有的材质一项都没有，这时用[涂装](#livery)里的漆面或涂装层。

## 在别的软件里画

**发布** 菜单里有 **导出 OBJ 模型（分部件）…**、**导出 OBJ 模型（合并）…** 和 **导出 UV 模板图…**。在 Substance Painter 或 Blender 里画 OBJ，或在修图软件里照着 UV 模板画，画完再拖回来。

## 格式和尺寸

- 支持 png、jpg、jpeg、tga、tif、tiff、bmp、webp，打包时自动转换。
- 每个部件的 **贴图清晰度**（**贴图** 页贴图格子下面，和 **涂装** 页漆面下面是同一个设置）决定这个部件的贴图在游戏里多大：**自动**、256、512、1024、2048、4096（按长边，始终保持比例）。编辑器预览、打包和游戏里都按这个尺寸。**自动** 时有涂装的部件至少 2048（弹匣这类原版贴图只有 256 的小部件上的文字和面板线也清楚），没有涂装的保持图片原尺寸。旁边写着这个部件的贴图在游戏里约占多少显存。只有换了贴图或上了涂装的部件才有这个设置。
- **边长超过 8192 像素的图游戏读不了**，整个皮肤包都会被拒。尽量用 2 的幂（1024、2048 等）。
- 贴图越大越占显存。打包后 **概览** 里会显示这款皮肤的估算：256 MB 以内很轻，超过 512 MB 游戏可能卡顿。

# 底漆、笔刷、花纹、磨损 {#paint}

## 底漆

给整个部件上一种颜色。新底漆是红色、正常混合、不透明度 1。把 **混合方式** 设成正片叠底可以保留下面贴图的细节，或者把 **不透明度** 稍微调低，让游戏贴图透出来。打开 **画遮罩** 留出不上色的地方（见[遮罩](#masks)）。

## 笔刷

直接在 3D 视图里往部件上画。选中笔刷层时，视图上方会出现工具条：

| 设置 | 范围 | 作用 |
| --- | --- | --- |
| 画法 | 自由画、直线、圆、填满一块 | 填满一块：点一下涂满整块 UV 岛。 |
| 粗细 | 0.5 到 30 毫米 | 笔画宽度。 |
| 镜像 | 开 / 关 | 同时在枪的另一侧对称位置画（按枪的中心平面镜像），填满一块也一样。 |
| 画遮罩 | 开 / 关 | 拖动时画的是遮罩而不是颜色。 |

右侧面板的 **清空笔画** 删掉这一层所有笔画。

## 花纹

![花纹层：预设、花纹、四个颜色、大小、旋转、种子](shot:pattern-layer)

1. 加一层 **花纹**，默认是美式林地。

# 贴花、贴纸和文字 {#decals}

贴花、面板线和文字都是**投射**上去的：它们在部件上占一个盒子，印在表面上，拖动时贴着表面滑，跟着曲面转。

## 往枪上贴一张贴花

1. 选中部件，[涂装](editor:livery)，**贴花**。
2. 从贴纸库里选一张、选自己的，或点 **用图片文件…**。
3. 在 3D 视图里点部件上要贴的位置，再拖动让它沿表面滑。
4. 在 **位置** 小节里用数值细调。

![贴纸库：28 张自带贴纸，下面是你自己的贴纸](shot:sticker-dialog)

自带贴纸是白色图形，用贴花的 **着色** 上色。**导入图片** 会把你自己的图片复制进编辑器的数据文件夹，以后每个皮肤都能用（png、jpg、jpeg、webp、bmp、gif）。自己贴纸上的 **×** 把它移出贴纸库；已经用了它的皮肤不受影响。

## 位置

![投射类图层的位置设置](shot:placement)

| 设置 | 范围 | 默认 | 作用 |
| --- | --- | --- | --- |
| 位置（毫米） | X、Y、Z | 你点的位置 | 和拖动是同一套数值，是在所属部件上的坐标。 |
| 朝向（度） | X、Y、Z | 跟随表面 | 盒子朝哪边。 |
| 大小（毫米） | 宽、高，至少 1 | 宽 40，高按图片比例 | 文字没有这项：宽度跟着字走。 |
| 旋转 | −180 到 180° | 0 | 在表面上转动图片。 |
| 投射深度（毫米） | 至少 0.5 | 10 | 向表面里外印多深。太深会印到部件另一面，太浅在曲面上会被截断。 |
| 镜像 | 开 / 关 | 关 | 只有贴花有：把图片左右翻转。 |
| 左右对称 | 开 / 关 | 关 | 在枪另一侧的对称位置也放一份。文字在那一侧也是正着读的。 |

显示 **还没放上去** 的层，在 3D 视图里点一下它的部件就好。

## 动图贴花

多帧的 `.gif` 贴花会多出 **动画** 小节，在游戏里像动态图层一样播放：选什么时候播、怎么播（**循环**、**播放一次**、**循环 N 秒**）和 **帧率**（1 到 60；不设就用它自己的帧率）。播放前显示第一帧。上下其他涂装层会烘进每一帧。帧多又大、一张游戏动画图放不下时，每帧会自动缩小，编辑器会提示。

## 文字

![文字层：文字内容、字体、字高、字距](shot:text-layer)

1. [涂装](editor:livery)，**文字**。默认是 Orbitron 字体的 `FORGE`。
2. 输入文字（框里最多显示 4 行，回车换行）。
3. 选字体（系统已装字体、自带的科技和标题字体，或一个字体文件），设 **字高** 和 **字距**。
4. 在 3D 视图里点部件放上去，再拖动。

| 设置 | 范围 | 默认 |
| --- | --- | --- |
| 字高 | 1 到 60 毫米 | 8 毫米 |
| 字距 | −0.1 到 0.6 | 0.08 |

文字和贴花一样有 **外观**、**位置** 和 **遮罩** 小节。

# 渐变和平铺图 {#gradient}

## 渐变

在部件上铺一道颜色渐变，可以是直线的，也可以从中心向外。默认沿部件最长的方向，从深蓝到青色。

![渐变层：渐变条、颜色、形状和方向](shot:gradient-layer)

1. [涂装](editor:livery)，**渐变**。
2. 点色块改颜色，拖它的滑块在渐变条上移动位置。**加一个颜色** 会在间隔最大的地方中间加一个（2 到 4 个颜色），**×** 删除一个。颜色可以半透明。
3. 选 **形状**（**直线** 或 **从中心**）和 **方向**：**沿枪身**、**上到下**、**左到右** 或 **中心向外**。
4. 用 **起点（毫米）** 和 **终点（毫米）** 细调两端在部件上的位置。

## 平铺图

一张图按你设的大小在部件上重复铺满，从三个方向投上去，跨贴图接缝也连得上。适合碳纤维编织、握把纹理，或在枪托上重复一个标志。

1. [涂装](editor:livery)，**平铺图**，选一张图：从 **我的平铺图** 里选（先用 **导入图片** 导入一次），或任意文件。
2. 设 **每块大小**（2 到 300 毫米，默认 30 毫米）和 **花纹旋转**（X、Y、Z）。
3. **外观** 里的 **着色** 给图片染色。

# 遮罩 {#masks}

每个涂装层都有 **遮罩** 小节：遮罩画到哪里，这一层就在哪里被隐藏。

## 画遮罩

1. 选中这一层，打开 **画遮罩**（在 **遮罩** 小节里，或视图上方的工具条里）。
2. 在部件上拖动画遮罩：**自由画**、**直线**、**圆**，或 **填满一块**（点一下遮住整块 UV 岛）。**粗细** 0.5 到 30 毫米；**镜像** 两侧一起遮。
3. 关掉 **画遮罩** 回到摆放或绘画。**清除遮罩** 删掉所有遮罩笔画，旁边显示已画几笔。

## 渐变遮罩

**渐变遮罩** 让这一层沿一个方向或从中心向外渐渐变淡，不用画。

| --- | --- | --- | --- |

| 方向 | 沿枪身、上到下、左到右、中心向外 | 沿最长的方向 | 按部件大小设好起点和终点。 |
| 起点 / 终点（毫米） | X、Y、Z | 部件两端 | 渐变的两端。 |

# 配色变体、调色板和玩家可调颜色 {#colors}

什么都没选时，右侧 **概览** 里有三个和颜色有关的小节。

![概览：配色变体、调色板和玩家可调颜色](shot:overview)

## 配色变体

同一款皮肤的几套配色，比如一套夜间版。皮肤有了涂装层才会出现配色变体。

1. 点 **新建配色**。它从现在显示的颜色开始，并被选中。
2. 改涂装颜色。选中一套配色时，改颜色只改这一套，图层本来的颜色不变。
3. 点 **原始配色** 回去。在列表下面的输入框里给配色改名，垃圾桶删除它。

卡片上的 **应用** 用当前选中的那套。导出的模组里每套配色都是单独一个皮肤，名字是「皮肤名 · 配色名」。Skins 枪包格式只带原始配色。

## 调色板

调色板是一组最多 8 个颜色，存在编辑器的数据文件夹里，所有皮肤都能用。

- **存下本皮肤的颜色**：输入名字（也可以不填），点保存图标。会存下涂装层用到的前 8 个不同颜色。
- 点一个调色板的名字：所有取色器下面都会列出它的颜色。再点一次取消。
- **给这个皮肤换上这组颜色**（魔杖图标）：皮肤的第 n 个颜色换成调色板的第 n 个，透明度不变。算一步撤销；选中配色变体时改进这套变体。

## 玩家可调颜色

可以让玩家在游戏里自己改你皮肤的颜色。

1. 点颜色设置旁的**小人按钮**，把它变成玩家可调颜色，或让它跟一个已有的一起变。
2. 在 **玩家可调颜色** 里给每个颜色起名、设默认色。
3. 想给玩家几套现成的颜色，就在部件列表最上面点 **整把枪**，在 **配色方案** 里调好颜色后点 **存成一套**；可以存好几套，**原色** 是各颜色的默认色。

一个玩家可调颜色可以同时管着色、发光色、挂件颜色、屏幕数字、底板、边框、低弹药色和特效的闪光色。游戏里大厅「皮肤」挑选器的颜色页把你存的配色方案列成卡片，玩家点一下就整套换上；每个玩家可调颜色下面还有它的默认色和一排色相可选。

# 动态图层 {#layers}

动态图层是部件上会动的贴图：**图片**、**序列帧**（按文件名里的数字排序的一组图）、**视频**（MP4）或 **文字**。从[动态](editor:layers)加，从部件的 **+**（**动态贴图**）加，或者选中部件后把图片、序列帧或视频拖进窗口。

1. 在部件贴图的 2D 预览里拖动图层移动位置，拖角缩放，拖顶上的圆点旋转。3D 视图同步播放。
2. **放置** 里：**贴到通道**（基础色或自发光）、**UV 位置**、**大小**、**旋转 °**、**不透明度**、**裁剪**。
3. **播放** 里：**触发**、**播放方式** 和 **帧率**。

| 设置 | 范围 | 默认 | 作用 |
| --- | --- | --- | --- |
| 触发 | 始终，或一个事件 | 始终 | 事件：击杀、命中、未命中、开火、空仓扣扳机、换弹开始和完成、装备、收起、瞄准、结束瞄准、弹药不足、弹匣打空、捡到弹药、开手电、关手电、倒地、被救起；物品有使用、拿出和收起/放下。近战和工具只列它们能做的。 |
| 播放方式 | 循环、播放一次、循环 N 秒 | 循环 | 按事件触发时：事件前显示普通贴图，事件发生后播放；再次触发会从头播。 |
| 循环 N 秒 | 至少 0.1 秒 | 3 秒 | |
| 弹匣低于 | 5 到 90 % | 20 % | 用于弹药不足。 |
| 帧率 | 1 到 60 | 12 | 视频按这个帧率拆成图片，最多 240 帧。 |

文字图层有 **字体**、**字号 px**（至少 8，默认 64）、**颜色** 和字距。

> [!WARNING]
> 帧在游戏里占显存。帧多、图层大最占；打包后 **概览** 里会显示估算。

# 代码特效 {#codefx}

代码特效是游戏用 ForgeCore 的绘制程序实时画出来的动态花纹：流光、扫描线、脉冲、噪声、边缘光和极坐标花纹。一款皮肤**最多 8 个**。它们不需要往包里放图片，还可以让玩家在游戏里改数值。

![前部上新加的代码特效](shot:code-effect)

## 加一个

1. 在左侧列表点部件行上的 **+**，在 **代码特效** 下点 **在这个部件上画动态花纹**。
2. **画在哪**：**画在** 部件自己的材质上（画进它的贴图，盖在图片和动态图层上面）或一个挂件模型上；**画进** 基础色或自发光。
3. 选 **花纹**，设它的数值和颜色。
4. 设 **大小与动作** 和 **什么时候出现**。**在 3D 视图里触发一次** 播放一次事件效果。
5. 打开数值旁的小人按钮，玩家就能在 「皮肤」挑选器的「调整」页改这一项。改的结果只存在他自己电脑上。

3D 预览用的是和游戏同一份花纹代码。

## 大小与动作（所有花纹都有）

| 设置 | 范围 | 默认 |
| --- | --- | --- |
| 大小 | 0.1 到 8 × | 1 |
| 旋转 | −180 到 180° | 0 |
| 转速 | −360 到 360 °/秒 | 0 |
| 强度 | 0 到 4 × | 1 |
| 叠加方式 | 盖上去、发光叠加 | |
| 什么时候出现 | 始终，或一个事件加 **持续（秒）** | 始终 |

## 各种花纹

| --- | --- | --- |

# 挂件和部件调整 {#attach}

挂件是额外装在枪上的东西：弹药屏、你自己的模型、自带形状和挂饰。选中部件，点[挂件](editor:attach)，**添加挂件**：

- **弹药屏**：实时显示数字或进度条，见[弹药屏](#screen)。
- **导入模型（.glb / .gltf）**：任意 .glb 或 .gltf 模型。模型自带的贴图（基础色，有的话还有自发光、法线、金属度/粗糙度）一起带入，编辑器和游戏里都显示，边长超过 2048 的缩到 2048；**颜色** 叠在贴图上，做成全息时基础色贴图就是发光的画面。
- **图片全息屏…**：选一张图片（png、jpg、webp），做成一块显示这张图的全息屏，见[图片全息屏](#holo-image)。
- **形状**：自带的全息形状，见[形状和全息](#holo)。
- **成套全息**：一次加几个同样风格的全息，按枪的部件摆好，见[成套全息](#holo-sets)。
- **挂饰**：用绳吊起来的导入模型或形状，见[挂饰](#charms)。

![机匣的挂件页](shot:attach-tab)

左侧列表里部件行的 **+** 菜单也有这些：

![部件的 + 菜单：能加给它的所有东西](shot:add-menu)

## 移动、旋转、缩放

新挂件装在选中部件的正上方；之后可以用 **挂载** → **挂在部件** 换到别的部件。

- 在 3D 视图里按 <kbd>G</kbd> 移动、<kbd>R</kbd> 旋转、<kbd>S</kbd> 缩放，或直接拖手柄。移动时按 <kbd>X</kbd>、<kbd>Y</kbd>、<kbd>Z</kbd> 锁轴；单击或 <kbd>Enter</kbd> 确认，右键或 <kbd>Esc</kbd> 取消。
- 打开视图上方工具条里的 **贴到表面**，点枪身，选中的挂件就平贴在点到的表面上：背面贴着表面、正面朝外，正着朝向当前视角。弹药屏、全息形状和图片全息屏都可以这样放。这时点挂件不会选中它；按 <kbd>Esc</kbd> 或再点一次按钮退出。
- **位置** 页里有数值：**位置 mm**、**旋转 °**、**缩放 ×**（锁链保持等比）。在数字上左右拖动可以改（<kbd>Shift</kbd> 细调，<kbd>Ctrl</kbd> 吸附）。**始终朝向镜头** 让它一直对着观看者。
- 左侧列表里挂件行的 **复制一份** 复制它；右侧面板的垃圾桶删除它。

## 挂件的外观和特效

- **外观** → **模型外观**：**颜色** 和 **不受光照（自身发亮）**。
- **特效** → **添加特效**：**闪光** 让挂件按一个颜色和 **亮度** 亮一下；**显示** 只在一段时间里显示它（比如只在瞄准时）。每个特效有自己的事件和秒数（至少 0.05；新加的是击杀时闪 0.4 秒，亮度 4）。

## 改部件本身

部件的[位置](editor:place)页可以移动、旋转、缩放或隐藏部件（**隐藏（游戏里也隐藏）**）；**重置全部** 和 **恢复原版** 改回来。有自己模型的部件在 **挂件** → **模型** 下有 **替换模型…**：你的 .glb 只替换这个部件的模型，子部件保留，贴图和材质照样生效，位置、旋转和缩放也还能改。**恢复原版模型** 撤销替换。

## 音效

[音效](editor:sounds)（任何选中对象都有）在击杀、弹药不足、倒地、被救起等时刻播放声音，每条最长 10 秒。装了这个皮肤的队友只听得到开火、拿出和收起、倒地、被救起这几种，声音从你的枪那里传出。音量只在这里调。

- **添加音效** 先选事件，再选文件（wav、mp3、ogg、flac、m4a、aac、opus、webm），打包时转成 Ogg Vorbis。
- 一个事件可以放好几条声音：每次按 **权重** 随机抽一条（概率 = 它的权重 ÷ 这组的总权重），不会连着两次抽到同一条。
- 击杀可以按敌人分组：在 **哪个敌人** 里选（游戏数据里的所有敌人，可以输入搜索）。其余击杀播 **任意敌人** 那一组。
- 倒地和被救起只给当时拿在手里的那件装备播放。

# 形状和全息 {#holo}

形状是用几个数值生成的自带模型：线、环、准星、网格、蜂巢护盾等。从 **形状** 里加的形状默认就是**全息**，颜色取皮肤的颜色（第一个玩家可调颜色，没有就取第一个有颜色的涂装层，再没有就用青色）；实心形状默认是线框。

![形状的外观：1 形状的数值，2 全息开关和它的设置](shot:hologram-look)

## 加一个全息形状

1. 选中部件，点[挂件](editor:attach)，**添加挂件**，**形状**，选一个形状。（也可以在 **概览** 的 **全息形状** 里加。）
2. 用 <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> 或 **位置** 页的数值把它摆好。
3. 打开 **外观**：先设形状的数值，再设 **全息**。

## 图片全息屏 {#holo-image}

**添加挂件** → **图片全息屏…**，选一张 png、jpg 或 webp 图片。编辑器把图片复制到皮肤旁边（边长超过 2048 的缩到 2048），做成一块宽 30 毫米、高按图片比例的全息屏，名字是图片的文件名。图片就是发光的画面：黑色的地方透明，**颜色** 是白色时保持图片原来的颜色，换成别的颜色就给画面染色。在 **外观** 的 **图片** 里改 **宽**、**高**；用 **贴到表面** 把它贴到枪身上。

## 成套全息 {#holo-sets}

**添加挂件** → **成套全息**，一次加几个风格一致的全息：同样的线宽和刻度长度、同样的从皮肤颜色到浅色的渐变、同样的闪烁和轮廓光。编辑器按当前装备的部件摆好：

| 套 | 里面有 | 放在哪 |
| --- | --- | --- |
| 瞄具刻度组 | 下方留口的刻度弧、里面一个环 | 瞄具正前方（没有瞄具就在机匣前部上方） |
| 枪管刻度环组 | 3 个刻度准星环，越靠近枪口越小 | 套在枪管前端 |
| 信息条 | 线框面板、里面两条数据条 | 机匣左侧（玩家看得到的一侧），朝外 |

加好后每一个都是普通的形状挂件，名字是「套名 · 形状」，可以分别移动、改数值或删掉。轮廓光每个全息占一个代码特效名额（每个皮肤最多 8 个）：剩下的名额不够时，这一套不带轮廓光加入，编辑器会提示；腾出名额后在 **外观** 里打开。

## 游戏里和编辑器里

游戏用自带的全息着色器画全息，它自己没有颜色渐变、扫描线和轮廓。所以：

- **双色渐变** 在打包时烘成模型上的一张小图，游戏里和编辑器里看起来一样。
- **扫描线** 和 **轮廓光** 变成这个挂件上的两个代码特效（ForgeCore 的扫描线和边缘光花纹），**各占皮肤 8 个代码特效名额中的一个**。你的代码特效加上它们超过 8 个时，编辑器会拒绝打包并提示，关掉几个就好。
- 闪烁和亮度是着色器自己的，在游戏光照下可能略有不同。进游戏看一次。

# 预览 {#preview}

3D 视图就是预览，每次改动立刻显示。

- 视图下面的事件按钮（击杀、命中、未命中、开火、换弹开始、装备、瞄准、弹药不足等）按游戏的规则播放动态图层、挂件特效、代码特效和音效。

# 保存、快照和装进游戏 {#save}

## 保存

- 每次改动约 1.5 秒后自动存进编辑器的数据文件夹，状态栏显示 **已自动保存**。
- 安装版的数据文件夹是 `文档\ForgeSkin`，免安装版是程序旁边的 `GTFO_UserData`。**设置** → **数据文件夹** 可以打开它，或用 **更换位置…** 搬走：选一个空文件夹，皮肤和缓存会整份复制过去，核对无误后才删掉原来的。搬移没完成时，数据留在原处。
- <kbd>Ctrl</kbd>+<kbd>S</kbd> 或卡片的 **更多** → **保存为文件…** 另存一份你自己的 `.forgeskinproj` 工程文件，以后保存会覆盖它。<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> 存成一个新皮肤。

## 版本快照

快照把皮肤现在的样子存下来，以后随时能回到这个版本，关掉软件也不会丢。卡片 **更多** → **版本快照**：输入名字（不填就用当前时间），**存快照**。**恢复** 前会先把现在的样子自动存成一个快照，也可以按 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤销这次恢复。

## 装进游戏

1. 在左栏作品列表顶部的 **应用到：** 选配置档（装了 BepInExPack_GTFO 的 r2modman 配置档）。列表里没有就用 **选择文件夹…** 加进来。
2. 点作品卡上的 **应用**（当前作品也可按 <kbd>Ctrl</kbd>+<kbd>Enter</kbd>）。编辑器按需装插件、打包皮肤、装进配置档，并让游戏给这件装备用这款皮肤。
3. 游戏开着时几秒内就能看到变化；没开就下次启动生效。
4. 游戏里点**大厅的「皮肤」** 查看和切换皮肤。

每张作品卡的图左上角写着它在这个档案里的状态（每组里正在用的排最前，然后在档案里，然后只在编辑器）：

- **只在编辑器**：游戏看不到。
- **在档案里**：游戏的皮肤页里能选，但没穿。
- **正在用**：游戏里这件装备穿的就是它，标记是绿色，整张卡描绿边，卡上没有按钮。想换回原版，在游戏里的皮肤挑选器换，包留在档案里。
- **有改动未应用**：装进档案后又改过，游戏里还是旧的；卡上名字下面的小字换成这句，点 **应用** 更新。

同一件装备只有一款正在用；应用另一款，前一款就回到「在档案里」。鼠标移到卡上，图右上角出现 **⋯**；右键卡片也能弹出同一份菜单，里面还有 **装进档案** 和 **从档案移除**：装进档案只装进去，不穿上。

这个档案里别人做的包收在列表顶上的一条里（写着还有几个，点开看卡片），**全部搬过来** 把它们变成你的作品；人物包也能搬，骨骼匹配和各项设置照包里的，模型本身不能重新导入。别人发给你的包，用 **新建** 旁边箭头里的 **添加皮肤包…** 装进档案。左栏右边缘可以拖宽。

**设置** 里的 **自动应用**（默认关）：开着时，游戏开着的情况下，正在用的作品改完停 2 秒就自动应用，只在出问题时提示。

> [!WARNING]
> 应用会往那个配置档里写真实的文件。请用专门测试的配置档；要给别人用，走 **发布**。

# 发布和分享 {#publish}

![发布菜单](shot:publish-menu)

- **检查**：导出前把所有皮肤过一遍，列出要改的地方。点一条问题就跳到那里。
- **导出皮肤包…**：一个包含全部内容的 `.forgeskin` 文件。
- **导出为 Thunderstore 皮肤模组…**：可以直接上传 Thunderstore 的模组，能放任何装备的皮肤。填模组名（英文字母、数字和下划线）、形如 1.0.0 的版本、简介（最多 250 字）和图标（缩放成 256 × 256；默认用装备的缩略图）。三种格式：
  - **ForgeSkin**：全部效果，由 ForgeSkin 插件应用。
  - **Skins：每个皮肤一组**：给装了 Skins 库的玩家。每个皮肤各是一个皮肤组；同一把武器可以放几个，玩家在游戏里挑。
  - **Skins 枪包**：整个模组是一个皮肤组；给每把武器选一个皮肤（或「不放进」）。
  - Skins 只带静态贴图和材质参数。动态图层、挂件、音效、部件调整、磨损阶段、代码特效和玩家可调颜色带不上，物品皮肤跳过，导出后会列出所有没带上或被改写的内容。
- **导出 OBJ 模型（分部件）…**、**导出 OBJ 模型（合并）…**、**导出 UV 模板图…**：拿去别的软件里画。

## 直接改游戏文件

不用插件：贴图和材质参数（金属度、光滑度、发光、颜色）在备份原文件后直接写进游戏自己的资源文件。挂件、屏幕、动态图层、音效和部件调整写不进去。

- **替换游戏原版资源…** 先列出要写什么、跳过什么，确认后才写。先关掉游戏；下次启动游戏生效。
- **还原游戏原版资源…** 把备份放回去，可以按皮肤还原或全部还原。
- **导出游戏资源包…** 把改好的游戏文件和一份写着安装步骤的 README 存成 zip，给没装这个软件的玩家用。不动你的游戏文件夹。一个资源包只适用于做它时的那个游戏版本。

游戏更新或 Steam 验证文件完整性会把原文件换回来。

# 常见问题 {#faq}

## 皮肤在游戏里很糊

- 最常见的原因是游戏的**贴图质量没开满**。这时 「皮肤」挑选器会显示一条黄色提示，说贴图只按原尺寸的几分之一显示。在游戏设置里把贴图质量开到最高。
- 看一下那个部件的 **贴图清晰度**（**贴图** 页或 **涂装** 页），调大一档；再看图片本身是不是太小。

## 皮肤包没加载

游戏读不了的包不起作用，「皮肤」挑选器右侧会用红字列出它和原因。常见原因：

- 缺文件：包里写到的图片、声音或模型不在。重新应用或导出一次。
- 图片坏了或太大：只支持 PNG 和 JPEG，边长最多 8192 像素。
- 声音坏了：必须能转成 Ogg，最长 10 秒。
- 路径不对：包里的路径不能是绝对路径，也不能带 `..`。一般是包被手改过，重新导出即可。
- 代码特效太多：自己的代码特效加上全息扫描线和轮廓光超过 8 个。
- 插件太旧：编辑器提示 ForgeSkin 或 ForgeCore 版本太旧时，在 r2modman 里更新它们。

## 点了应用，什么都没变

- 看左栏顶部 **应用到：** 写的档案是不是你玩的那个。
- 档案的插件要更新而游戏开着时，左栏会写「插件待更新，关游戏后自动装」：关掉游戏，编辑器会自己装好，再点一次 **应用**。
- 每件装备同时只穿一款皮肤：看卡片是不是 **正在用**，不是就点 **应用**。

## 人物卡点「应用」说骨骼没对上

骨骼还没对上。打开 **骨骼匹配**，把红色的关节处理完，直到写着 **骨骼都对上了，姿势核对通过。**（见[骨骼匹配](#char-bones)）。

## 人物在游戏里还是原版的样子

- 在大厅的 **皮肤** → **人物** 里看选的是不是你的人物。
- 游戏开着时装的人物，要下次进关卡才换上。
- 队友没装你的人物模组，或装的版本不同，他们看到的是原版人物。

## 「找不到皮肤插件文件」

编辑器自带要装进配置档的插件。这条提示说明编辑器自己身上少了这些文件。按你运行编辑器的方式修：

| 运行方式 | 怎么修 |
| --- | --- |
| 安装版（Setup.exe） | 重新运行最新的 Setup.exe。插件在安装目录的 `app-<版本>\resources\publish\plugin` 下；你的数据文件夹（`文档\ForgeSkin`）不受影响。 |
| 免安装 zip | 把整个 zip 重新解压到同一个文件夹。`resources\publish\plugin\ForgeSkin\ForgeSkin.Plugin.dll` 和 `resources\publish\plugin\ForgeCore\ForgeCore.dll` 必须在；程序旁边的 `GTFO_UserData` 会保留。 |
| 从源码运行 | 在仓库根目录运行 `pwsh Mods/ForgeSkin/tools/build-editor-release.ps1 -PluginOnly`，再重启编辑器。开发版发现插件没构建时会自己跑这一步；失败的话日志里有一行 "plugin staging failed" 和原因（通常是 BepInEx 配置档路径：加 `-BepInEx <配置档>/BepInEx` 或设 `GTFO_BEPINEX_PATH`）。 |

## 日志

![设置：语言、自动应用、游戏和数据文件夹](shot:settings-menu)

左下角状态栏的日志按钮打开日志面板，编辑器和游戏插件的消息都在里面。游戏开着时，游戏里的问题（某个部件没换上皮肤、某个包没加载、某个代码特效被跳过）会写进日志并在右下角弹出。

# 用 AI 操作编辑器 {#ai}

AI 代理（Claude、Codex 或脚本）可以通过 Chromium 开发者工具协议操作编辑器。用 `--ai-control` 启动时，编辑器在 127.0.0.1 上开一个调试端口，并提供 `window.forgeAI`：一套结构化接口，能做编辑器的所有事：把皮肤读成 JSON、改任何字段、按 UV 放贴花、设镜头、渲染 3D 视图。文件对话框会变成窗口里的路径输入框，代理可以直接填路径。

## 给代理启动编辑器

| 版本 | 启动方式 |
| --- | --- |
| 安装版 | `& "$env:LOCALAPPDATA\ForgeSkin\ForgeSkin.exe" --ai-control` |
| 安装版，用开始菜单快捷方式 | 先运行一次 `setx FORGESKIN_AI_CONTROL 1`，之后照常启动 ForgeSkin（`setx FORGESKIN_AI_CONTROL ""` 关掉） |
| 免安装版 | 在解压出的 `ForgeSkin-win32-x64` 文件夹里运行 `ForgeSkin.exe --ai-control` |
| 源码 | 在 `Mods/ForgeSkin/Editor` 里运行 `pnpm start -- -- --ai-control` |

`--ai-control=9444` 指定端口（1024 到 65535，默认 9333）。打开 `http://127.0.0.1:9333/json/list` 检查：应该列出一个标题为 ForgeSkin 的页面。

> [!WARNING]
> 先关掉你正开着的编辑器：两个编辑器会共用一个数据文件夹和设置。另外请用测试配置档；**应用** 会写真实的文件。

## 给代理看什么

让它读 ForgeSkin 源码里的 **AI-GUIDE.md**（`Mods/ForgeSkin/AI-GUIDE.md`）。里面列了 `window.forgeAI` 的所有命令、文档路径、路径对话框和主流程，以及每一步怎么判断成功。可以先试这几句：

```js
await forgeAI.state()                                   // 当前装备、皮肤、选中项和整个皮肤
await forgeAI.command('selectWeapon', { id: 'helr' })   // 打开 OMNECO LRG
await forgeAI.command('help')                           // 所有命令和参数
```
