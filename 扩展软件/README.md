# GTFO 枪皮工坊 v0.1.52

Windows 桌面工具，用于把用户提供的枪皮贴图写入 GTFO 的 `sharedassets*.assets`，
或导出到任意目录后再手动安装。

![界面预览](artifacts/ui-preview.png)

## 功能

- 顶部提供“枪皮工坊 / DLY 弹夹显示”独立工作区切换，两套页面状态互不混合
- DLY 工作区提供 HEL 整枪 3D 预览，可点击枪模选择前部、机匣、枪托、弹匣、瞄具、枪灯和弹药部件
- DLY 屏幕支持毫米级 XYZ 偏移、XYZ 旋转、尺寸、缩放、表面间隙和颜色实时预览
- DLY 顶部和当前锚点部件的“对象”列都提供独立“子弹显示屏幕”选择；背板和边框透明度均为 0 时仍可通过透明拾取代理选中和编辑
- DLY 显示框提供与游戏透明度无关的橙色编辑轮廓、四角控制点、红绿蓝坐标轴和“聚焦显示框”
- DLY 提供移动 `G`、旋转 `R`、缩放 `S` 模态变换；`G/R` 后按 `X/Y/Z` 锁定枪模局部轴，左键或 Enter 确认，右键或 Esc 回滚
- DLY 旋转工具提供三条彩色圆环，缩放工具提供中心控制柄；右侧毫米/角度数值与 3D 变换保持同步
- 提供正面、背面、左侧、右侧、顶部、底部和等轴测固定视角；`Alt+右键` 拖动观察，松开后自动吸附最近固定面
- 数字键 `1/3/7` 快速切换正面、右侧、顶部，`5` 切换透视/正交视图
- 可启用“吸附到对应面”，点击枪模时按实际命中点放置屏幕并朝向命中三角面
- 每个部件行前都有独立隐藏按钮，可单独隐藏或恢复任意枪模部件
- 部件列表的隐藏按钮采用 Photoshop 风格小眼睛图标，固定窄列显示
- 背板和边框不透明度可独立调整
- DLY 预设可自动保存，并可把所选部件锚点、偏移和样式直接写入当前测试档的 `BepInEx/config/Yuyu.HelAmmoDisplay.cfg`
- 便携包内置 DLY 插件 1.5.1；应用新插件前检测 GTFO 是否运行，并保留旧 DLL 的 `.bak` 备份
- 插件 1.5.1 把屏幕直接设为所选枪模部件 Transform 的子节点，CConsole 旋转、动画、后坐力和 ADS 会带着屏幕运动
- 编辑器保存的精确绝对模型坐标优先于归一化坐标，避免部件包围盒差异造成游戏内位置偏移
- 屏幕位置使用锚点局部坐标，固定朝向不再在每帧重设世界位置；面向相机模式只更新屏幕世界旋转
- 所选部件运行时包围盒的归一化坐标继续用于映射编辑器位置，避免编辑器与游戏模型原点/轴方向不一致
- 绝对坐标模式下只使用 `AnchorLocalX/Y/Z`，不再叠加偏移；测试档配置变化后约 0.5 秒自动刷新，不必反复切枪
- 自动定位 Steam / GTFO 安装目录
- 枪械、瞄具、镜片、枪灯和弹匣目录
- 左侧枪械按主武器、副武器分类，弹匣、枪灯、瞄具和镜片集中在独立枪械配件分区
- 主武器与副武器按官方游戏顺序排列，显示“官方中文类型 · 英文武器名”
- 每把枪按 Forge 默认装配 Gun Light A-D 或 PEQ-1；枪灯默认关闭，勾选后才参与贴图、导出和 3D 预览
- 大口径与小手枪枪灯使用手动 OBJ 反解出的精确灯体+镜片矩阵，旋转和衔接位置一致
- 贴图通道与部件智能识别，低置信度人工确认
- Albedo、Normal、MetallicSmoothness、Emissive 四通道替换
- 仅当识别到 Emissive 贴图时，显示该贴图的 R/G/B 发光颜色与强度参数
- 右侧 2D / 3D 预览切换，可在不启动 GTFO 的情况下查看整枪网格
- 3D 窗口提供“原生发光预览”，基础色保持正常受光亮度，仅 Emissive 贴图亮部额外发光；黑色区域不发光
- 3D 窗口提供全局环境光亮度滑块和颜色选择器；强度为 0 时所有场景灯关闭，只保留自发光
- 每把枪默认显示原生整颗子弹与空弹壳，两者为独立部件和独立贴图通道；空弹壳在左、整颗子弹在右，底部对齐
- 左轮武器增加原生六孔快速装弹器，映射表顺序为枪灯、快速装弹器、整颗子弹、空弹壳
- 枪械配件新增“子弹”分类，包含 9mm、.308、12G、.45 ACP 和左轮弹，每种均可独立替换整弹与空壳
- 所有部件左侧均有总勾选，枪灯和弹药默认勾选；取消后该部件从 3D 预览、导出和安装中移除
- 3D 环境光强度、颜色和原生发光预览开关会跨武器及软件重启保留
- 3D 操作为左键平移、右键旋转、滚轮快速缩放；默认开启并持久化约 30°/秒的自动旋转
- 顶部菜单提供“撤回”，可用 `Ctrl+Z` 恢复上一个映射、部件勾选或发光参数修改
- 武器内和独立弹药分类统一标注口径：`.308`、9mm、12G、`.45 ACP`、`.44`
- 自发光 RGB 参数位于映射表右下角，采用紧凑两位小数输入框
- 新增 OBJ 导出：支持每个勾选部件单独文件，或合并为一个多对象 OBJ；保留原生材质名称并生成 MTL 与导出清单
- 修复合并 OBJ 的顶点、UV 和法线索引没有跨部件连续编号导致的模型撕裂
- 修复 IronSights 4/8/9 的 F/B 备用模型重叠，以及 IronSights 10 无法显示官方网格的问题；同步修正使用这些瞄具的霰弹枪预览
- 全量复核 33 把武器和全部枪械附件；附件网格改为按 Renderer 的真实材质绑定提取，并修复 Sight 14/20/21 重复模型和不透明瞄具镜片缺失
- 自动备份目录改为 `YYYY-MM-DD-HHMMSS-备份-武器或部件全名`；OBJ 导出创建 `YYYY-MM-DD-HHMMSS-武器或部件全名.OBJ` 文件夹
- 武器相关界面提示、备份目录和 OBJ 文件夹统一使用左侧官方全名，例如 `狙击枪 · Köning PR 11`
- 多次 OBJ 导出始终使用独立日期时间目录；同秒导出自动追加序号
- 3D 预览标签更名为“3D 视图”，选中时仅显示绿色底色，不再使用边框高亮
- 自发光 R/G/B 每个通道右侧都有上下箭头，点击一次按 `0.1` 增减并立即刷新 3D 发光强度
- 3D 预览使用本地游戏高模，并通过 GTFO Forge 装配矩阵定位瞄具、弹匣、枪机和枪托
- 机关枪 2、连发步枪及手枪系列已补齐官方完整部件；枪灯 A-D 和 PEQ 支持独立 3D 预览
- 手喷全部部件按用户手动 OBJ 锁定；独头霰弹枪补齐精密枪托和 Flashlight E
- 自动备份、导出、安装和回滚
- `.gtfoskin` 工程保存

## 运行

```powershell
python -m pip install -r requirements.txt
python run_app.py
```

或直接运行：

```text
dist\GTFOSkinForge\GTFOSkinForge.exe
```

## 使用流程

1. 启动后软件会从 Steam 注册表、库配置和常见目录中查找 GTFO。
2. 左侧选择枪械或附件，点击“选择整枪贴图目录”。
3. 检查映射表中的橙色低置信度项；双击任意通道格可手动换图。
4. 在右侧检查四通道预览，按部件设置发光颜色、强度和遮罩。
5. 勾选必要的缺失项/低置信度确认，然后“生成并导出”或“安装到游戏”。
6. 安装前会自动备份目标文件；底部“还原上次安装”可恢复。

贴图尺寸默认为跟随原材质。软件只修改目标 `sharedassets*.assets`，
不会修改或删除原始 `.assets.resS`。

默认输出尺寸为“保持用户贴图尺寸”，不会把 2K/4K 输入自动缩小到官方
256/512/1024 的小图。需要与官方尺寸一致时，可在界面中主动选择
“跟随原材质”，或指定 1K/2K/4K。

纹理缩放始终保持原始宽高比，不会把弹匣等非方图强行压缩为正方形。

主界面底栏显示当前备份目录，“安装前自动备份”默认不勾选。勾选时如果尚未
设置目录，软件会要求选择。备份目录可以位于任意磁盘，包括 C 盘。旧版本保存在
`%LOCALAPPDATA%\GTFOSkinForge\backups` 的记录会在设置新目录时自动迁移。
不勾选时仍会临时保护安装过程，但安装成功后会删除临时数据，不保留历史记录。

## 测试

```powershell
$env:PYTHONPATH = "src"
python -m pytest
```

应用数据默认保存在软件所在目录的 `GTFO_UserData`。便携版放在 D 盘时，
备份、基准资产、缓存、日志、工程和配置都不会写入 C 盘。旧版本保存在
`%LOCALAPPDATA%\GTFOSkinForge` 的数据会在首次启动时自动迁移。

如果操作报错，请查看 `GTFO_UserData\logs\app.log`。
安装前需要关闭 GTFO 和旧版枪皮工坊实例，避免目标 `.assets` 被占用。

## 重新打包

```powershell
python -m PyInstaller --noconfirm --clean GTFOSkinForge.spec
```

打包结果位于 `dist\GTFOSkinForge`。
